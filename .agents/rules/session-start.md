# Session Start Rule

At the start of every session, before planning or making changes, complete this reading and orientation sequence:

1. Read the root `README.md` for repository structure and working conventions.
2. Read `CONTEXT.md` for company context and domain constraints.
3. Read `memory-bank/projectbrief.md` for project goals and business context.
4. Read `memory-bank/techContext.md` for the selected stack, architecture, and technical constraints.
5. Read `memory-bank/progress.md` for the current project status and planned work.
6. Read the `README.md` files for the folders in the proposed task’s scope, plus any relevant skill instructions.
7. Check the working tree for existing changes before editing. Preserve changes the agent did not create; do not overwrite or discard them.

If a required file is missing, inaccessible, or contradictory, stop and ask the developer for guidance rather than guessing. Do not begin implementation until this sequence is complete.
